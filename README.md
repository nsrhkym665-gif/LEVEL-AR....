# LEVEL AR — GitHub Pages (إصدار مُصلح)

هذا الإصدار يصلح المشاكل التي ظهرت في النسخة السابقة:

- صور الألعاب أصبحت ملفات SVG حقيقية داخل `assets/covers/` بدل صور Data URI تجريبية.
- كل لعبة أصبحت قابلة للضغط، وتفتح نافذة **آخر الأخبار والمعلومات**.
- بطاقات الأخبار لها صور فعلية داخل الموقع.
- مشغل الفيديو أصبح IFrame حقيقيًا للفيديوهات التي لها Video ID؛ والفيديوهات غير المرتبطة تعرض زر بحث واضح بدل رسالة وهمية.
- لا يوجد Backend أو Firebase أو قاعدة بيانات.
- الموقع يعمل على GitHub Pages.

## الرفع
ارفع **محتويات هذا المجلد** إلى مستودع GitHub كما هي، بحيث يكون `index.html` في جذر مصدر النشر.

> ملاحظة: صور الألعاب هنا بوسترات محلية مصممة للموقع وليست أغلفة رسمية مرخّصة. يمكن لاحقًا استبدال أي ملف داخل `assets/covers/` بصورة رسمية إذا كانت لديك حقوق استخدامها.
